# Borkeo EMR v43.7.0 - Top Bar Inline Patient Search & CSRF Auto-Recovery

Borkeo EMR version 43.7.0 transforms the top bar global search into a direct inline search input with an attached instant dropdown (eliminating popup modal panels) and implements automatic CSRF token auto-recovery for role and user-type switching.

## Key Enhancements

### 1. Direct Inline Topbar Search & Instant Dropdown
- **Direct Input**: In `public/app-shell.js` and `public/app-shell.css`, the center of the top bar features a direct `<input type="search" id="emr-global-search-input">`. Staff can click and type immediately without any modal dialog opening.
- **Instant Dropdown**: As text is typed, an inline dropdown menu (`#emr-topbar-search-dropdown`) appears right underneath the search box:
  - Displays matching patients with name, ID, age, sex, and department.
  - Arrow key navigation (↑ and ↓), Enter to open selected record, Esc or click outside to dismiss.
  - Zero modal panels or background dimming overlays.
- **Keyboard Shortcut**: `Ctrl + K` (or `Cmd + K`) focuses and selects the inline search box directly.

### 2. Automated CSRF Token Auto-Recovery
- When switching roles or changing user type for the Superuser account (`POST /api/auth/context`), if a 403 CSRF validation response is returned (e.g. from a tab left open or server restart):
  - The client automatically calls `/api/auth/me` with `cache: 'no-store'` to fetch a fresh CSRF token.
  - It automatically retries the context switch request with the new token.
  - Resolves "Security token is invalid" errors seamlessly without requiring manual user logout/login.

### 3. Standards & Compatibility
- 100% preservation of patient database schemas, data integrity, and authentic Khmer UI text.
- Full test suite passing.
