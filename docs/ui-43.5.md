# Borkeo EMR v43.5.0 - Unified Same-Row Registration Action Bar Documentation

## 1. Overview
Borkeo EMR version 43.5.0 unifies the patient registration form action controls so that the «រក្សាទុក» (Save) and «បញ្ជូនទៅផ្នែកទ្រីយ៉ា» (Send to Triage) buttons sit together in the same clean row at the bottom of the registration card (`#sub_reg`).

## 2. Key Architecture & Layout Changes

### Unified Action Bar (`#reg_action_bar`)
Previously, the Send to Triage button was placed within `.action-bar` at the bottom of the registration card, while the Save button was generated in a separate external box (`.emr-encounter-toolbar`) below the entire `#page1` element.

In v43.5.0:
- When viewing or editing registration (`current === 'register'`), `emr-encounter-editor.js` detects the registration action bar (`#reg_action_bar`) and prepends the editor toolbar directly into it.
- `.action-bar .emr-encounter-toolbar` is styled with clean transparent container properties, seamless flex alignment, and standard 10px spacing.
- Both buttons («រក្សាទុក» and «បញ្ជូនទៅផ្នែកទ្រីយ៉ា») are presented side-by-side in the same horizontal row with cohesive button sizing and hover feedback.
- If editing an existing patient, the «បោះបង់ការកែប្រែ» (Cancel) button and status indicator also appear in the same unified bar.

### Standards & Safety Safeguards
- **Frozen Storage Keys**: Zero impact on any indexed clinical keys or patient database tables.
- **Authentic Print Isolation**: The action bar and toolbar remain strictly hidden during printing via `@media print`.
- **Khmer UI Compliance**: Passed `npm run check:khmer`.
- **Test Suite**: 988 passing tests in `tests/*.test.mjs`.
