# Borkeo EMR v43.6.0 - Patient List Age Display Refinement

Borkeo EMR version 43.6.0 updates the patient list table so that the Age column displays exclusively the age badge (e.g. `7 ឆ្នាំ`, `71 ឆ្នាំ`), cleanly omitting the date of birth (DOB) string.

## Changes Overview

1. **Patient List Table Column (`public/patient-list.js`)**:
   - The age column cell (`<td data-column="age" class="patient-age">`) now renders exclusively:
     ```html
     <td data-column="age" class="patient-age">
       <span class="age-badge" data-patient-value>${escapeHtml(ageLabel(patient))}</span>
     </td>
     ```
   - The preceding `<span data-patient-value>${escapeHtml(formatDate(patient.dateOfBirth))}</span>` element has been removed from the table row markup.

2. **Resilient Age Computation Fallback**:
   - In `ageLabel(patient)`, if `patient.age` is blank or unpopulated while `patient.dateOfBirth` is present, the function automatically calculates the patient's age in completed years as of their entry date (or current date), ensuring an age badge is always displayed accurately.

3. **Compliance & Preservation**:
   - 100% preservation of all underlying patient records, database schemas, and frozen keys.
   - Khmer-only default UI text.
   - All tests passing.
