# Borkeo EMR v43.4.0 - Clean Registration View Documentation

## 1. Overview
Borkeo EMR version 43.4.0 enhances the patient registration interface by suppressing clinical summary headers, consultation cards, chart tabs, and breadcrumbs for registration users (`REGISTRATION` role) and registration views (`/emr?view=register` / Page 1 `#sub_reg`).

Registration staff now receive an uncluttered, distraction-free Patient Registration Form («ទម្រង់ចុះឈ្មោះអ្នកជំងឺ») situated immediately at the top of the interface.

## 2. Key Changes & Architecture

### Top Section Suppression
When a user is logged in with the `REGISTRATION` role, opens `/emr?view=register`, or switches to Page 1:
- **Breadcrumbs Container (`.emr-breadcrumbs-container`)**: Suppressed via `app-shell.js` and high-specificity CSS.
- **Sticky Patient Banner (`#emr-persistent-patient-banner`)**: `renderPatientBanner()` checks `isRegistrationUser()` and avoids mounting or removes the banner; styled with `display: none !important;`.
- **Chart Navigation Tabs (`#emr-chart-tabs-wrapper`)**: `setupChartTabs()` skips tab construction for registration users; styled with `display: none !important;`.
- **Clinical Summary Dashboard (`#emr-summary-dashboard-panel`)**: Suppressed along with chart tabs.
- **Clinical Consultation Workspace (`#emr-consultation-workspace`)**: `isConsultationActive()` returns `false` in registration context.

### Multi-Layer Safeguards
1. **Early Script Detection in `EMR.html`**:
   - Detects `view === 'register'` or `sessionStorage` role `REGISTRATION` prior to first paint.
   - Applies classes `registration-user`, `on-registration-page`, `bed-direct-register`.
2. **Session Role Integration (`emr-session.js` & `emr-permissions.js`)**:
   - Automatically injects `registration-user` and `data-user-role="REGISTRATION"` on session load.
   - Hides navigation buttons and top-level headers.
3. **Tab Switching Synchronization**:
   - `switchPage(pageNumber)` dynamically toggles `on-registration-page` on `<html>`.
4. **CSS Presentation Guard in `patient-banner.css` & `EMR.html`**:
   - Guaranteed CSS override with `!important` to eliminate any visual flicker.

## 3. Data Integrity & Compliance
- **Patient Data Preserved**: No database migrations or schema alterations; patient database remains untouched.
- **Frozen Storage Keys**: All existing 28 indexed storage keys and custom scopes preserved.
- **Authentic Print Isolation**: Registration paper documents and cards print without header or banner interference.
- **Khmer UI Compliance**: Passed `npm run check:khmer` with zero unapproved strings.
- **Test Suite**: 987 passing tests in `tests/*.test.mjs`.
