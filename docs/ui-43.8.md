# Borkeo EMR v43.8.0 - Patient List Deduplication, Edit Choice Dialog & Return Navigation

Borkeo EMR version 43.8.0 delivers patient list deduplication by Health ID, an edit choice action dialog with options to update information or add a new record, and return navigation back to the patient list after viewing or editing patient records.

## Key Enhancements

### 1. Patient List Deduplication by Health ID
- In `public/patient-list.js`, when multiple visits or records exist for the same patient sharing the same Health ID (`healthId`), the list displays only one row representing their latest visit.
- Patients without a Health ID continue to display distinct entries by `patientKey`.
- Triage today view retains all active triage queue items as needed.

### 2. Edit Action Choice Dialog (Pencil Icon)
- Clicking the pencil edit icon (`[data-request-edit]`) on any patient row now pops up an action choice window:
  - **«កែប្រែព័ត៌មាន» (Edit Information)**: Directs to the appropriate patient consultation or registration edit form (`mode=edit&from=patient-list`).
  - **«បន្ថែមកំណត់ត្រាថ្មី» (Add New Record)**: Directs to registration with `newVisitFrom` preset (`view=register&newVisitFrom=...&from=patient-list`), allowing quick intake of a new visit for the existing patient.
  - **«បោះបង់» (Cancel)**: Closes the popup modal.

### 3. Minor Navigation & Return to Patient List
- In `public/app-shell.js` and `public/patient-list.js`, viewing or editing a patient from the patient list appends `from=patient-list`.
- The breadcrumb bar on `/emr` and `/record-viewer` includes a direct link to return to `បញ្ជីអ្នកជំងឺ` (`/patient-list`).
- For registration views opened from the patient list, a return navigation link (`‹ បញ្ជីអ្នកជំងឺ`) is rendered at the top of the form for seamless one-click return.

### 4. Standards & Compatibility
- 100% preservation of patient database schemas, data integrity, and authentic Khmer UI text.
- Passes all automated test suites and strict Khmer compliance checks.
