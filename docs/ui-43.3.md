# Borkeo EMR v43.3.0 - Integrated Clinical Consultation Workspace Documentation

## 1. Overview
Borkeo EMR version 43.3.0 provides full integration between the modern consultation workspace (v43.2) and the detailed legacy clinical sections in the outpatient department (`#sub_opd`).

The interface gives physicians the speed and visual clarity of modern summary cards alongside the full depth of comprehensive hospital records (TB screening, ICD-10 diagnostic coding, and complete medication prescription matrices).

## 2. Integrated Architecture & View Modes

### View Mode Selector
A segmented view switcher is situated at the top right of the consultation card:
- **ទម្រង់រួមបញ្ចូលគ្នា (Integrated Form - Default)**:
  - Displays the 2-column Modern Consultation Workspace at the top (vitals cards, chief complaint, HPI, PE, diagnosis, plan, action buttons, tasks checklist).
  - Displays detailed clinical hospital sections seamlessly directly below the card:
    - **TB Screening Matrix (ការពិនិត្យស្វែងរកជំងឺរបេង)**: 8-point clinical screening checklist with card styling.
    - **ICD-10 Multi-diagnosis System**: Diagnosis search, tag cloud, and detailed diagnostic notes.
    - **Paraclinic / Investigations Builder**: Ultrasound, X-ray, CT-Scan, MRI, and Blood test category tools.
    - **Full Prescription Matrix (តារាងវេជ្ជបញ្ជាឱសថ)**: Full medicine table with autocomplete, dose, route, schedule, duration, quantity, and print order.
    - **Doctor Electronic Signature (ហត្ថលេខាគ្រូពេទ្យ)**.
- **ទម្រង់សង្ខេប (Modern Compact View)**:
  - Displays only the modern consultation card and tasks checklist widget.
- **ទម្រង់ពិស្ដារពេញលេញ (Full Classic Form View)**:
  - Displays the traditional hospital form layout directly, with a floating top return bar (`ត្រឡប់ទៅទម្រង់រួមបញ្ចូលគ្នា`) to return instantly.

### Live Two-Way Synchronization
- Edits made in modern cards are reflected into legacy DOM fields (`pmrs_chief_complaint`, `opd_bp_sys`, `opd_bp_dia`, `opd_pulse`, `opd_temp`, `web_triage_spo2`, `opd_resp`, `opd_weight`, `textarea[data-emr-key-index="13"]`, `textarea[data-emr-key-index="22"]`, `emr_pmrs_opd_diagnosis`, `opd_plan_notes`).
- Edits made in legacy sections immediately sync back to modern cards and update the tasks completion checklist.
- Dropdown action «បញ្ចូលវេជ្ជបញ្ជាទៅក្នុងផែនការ» automatically parses medications from the prescription table and formats them into the treatment plan notes.

### Standards & Safety Safeguards
- **Frozen Storage Keys**: All presentation inputs declare `data-emr-transient=""` and `data-emr-no-save=""`, preserving the 28 indexed storage keys without any index pollution.
- **Authentic Print Isolation**: `@media print` suppresses modern workspace and controls, ensuring 100% authentic hospital A4 paper printouts.
- **Khmer UI Compliance**: All UI labels, buttons, and placeholders are in approved Khmer only.
