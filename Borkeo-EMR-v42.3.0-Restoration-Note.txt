2. COMPLETE VERSION HISTORY & FEATURES (v42.3.0 to v44.0.0)
================================================================================

--------------------------------------------------------------------------------
Version 42.3.0 (Commit 4b80aa5) - The Restored Baseline
--------------------------------------------------------------------------------
- Integrated the Cambodia Essential Medicines List, 10th edition (704 medicines)
  into all prescription forms (OPD, IPD admission, daily note, discharge).
- Auto-completes CMS code, Name, Form, and Strength after typing 2 characters.
- Standardized unit mappings (mg, mL, mcg, g, IU).
- Route selection is required before saving (prevents accidental PO defaults).
- Initial prescription tables start with 3 clean rows.

--------------------------------------------------------------------------------
Version 42.4.0 (Commit 87cce71) - Cloud Deployment & Production Security
--------------------------------------------------------------------------------
- Docker & Railway hosting support (Dockerfile, .dockerignore, docs/DEPLOY.md).
- Strict Git privacy: all databases, uploads, backups, and logs permanently excluded.
- DATA_DIR support for persistent cloud volume mounts.
- Production security: Superuser password via environment variable; shared 1234
  passwords disabled in production.

--------------------------------------------------------------------------------
Version 42.5.0 (Commit 1c6d23e) - Filtered Prescription Picker & Max Dose Checks
--------------------------------------------------------------------------------
- 2-step prescription selection: search by generic medicine name, then select
  specific CMS code / form / strength.
- Automatic filtering by patient age, sex, pregnancy status, and service mode.
- Maximum dosage limits (adult and pediatric per kg) with alert warnings.
- Expanded routes: IV, IM, SC, PO.

--------------------------------------------------------------------------------
Version 42.6.0 (Commit 8c92552) - Midwife Services & Official 2026 ANC Record
--------------------------------------------------------------------------------
- Official 2026 Antenatal Care (ANC) pregnancy record (pages 2-5).

  with first-trimester ultrasound override.
- Midwife queue, vaccination tracking, and CPA3 doctor-signed referral letters.

--------------------------------------------------------------------------------
Version 42.8.0 (Commit 98198b0) - NPCA Integration & Patient Registration Cards

3. GIT TAGS REFERENCE (HOW TO SWITCH VERSIONS EASILY)
================================================================================
All past versions remain preserved as tags in your Git repository. You can inspect
or check out any version at any time:

- List all available tags:
    git tag -l

- Switch to any past version (e.g. v43.7, v43.8, v43.9):
    git checkout v43.7
    git checkout v43.8
    git checkout v43.9

- Return back to master (currently restored to v42.3.0 baseline):
    git checkout master
