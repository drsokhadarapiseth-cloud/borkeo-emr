BORKEO EMR v40.4.0 - COMBINED UPDATE NOTE
Base: v40.3.0. Clinical, pharmacy, laboratory and financial logic were preserved. Patient records are not touched.

WHAT CHANGED
1. (v40.4.0) Patient Photo in Ward Bed Popup Dialog:
   - In `/departments`, clicking an occupied patient bed opens the modal dialog (`openBedModal`) displaying the patient's photo (`.bed-patient-avatar`) next to their identity (name, sex, age, diagnosis, address, entry date, and payment status).
   - If the patient has a photo (`patient.photo`), it is displayed with clear dimensions (92×92px) with rounded corners and a soft frame so clinical and nursing staff can clearly identify the patient's face.
   - If no photo has been registered yet, an elegant neutral avatar placeholder with Khmer title «គ្មានរូបថត» is rendered.
   - The same clear patient photo also appears in the bed transfer dialog (`openBedTransferDialog`).
   - Clean responsive styling in `departments.css` adapts smoothly to mobile and desktop screens.
2. (v40.3.0) Instant Ward Editing for Nurses and Doctors:
   - Selecting nursing or medical records from bed actions opens directly in edit mode (`edit=1`).
3. (v40.2.0) Instant Triage Editing:
   - Triage queue "បំពេញទ្រីយ៉ា" opens in edit mode directly.
4. (v40.1.0) Role-based Chart Tabs in Patient Banner:
   - Chart tabs filtered by staff role.
5. Version 40.4.0 (package.json, login.html, server.mjs).

INSTALL (one step at a time)
  Step 1. Stop the running EMR if active (Ctrl+C in terminal window).
  Step 2. Start the EMR again: double-click Start-Borkeo-WiFi.bat or run `npm start`.
  Step 3. In the browser, press Ctrl+F5 on the EMR page to reload the updated scripts.
