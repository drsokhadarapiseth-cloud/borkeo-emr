================================================================================
Borkeo EMR Update Note: Version 42.2.0
Start-Borkeo-WiFi.bat no longer closes at once
================================================================================

Date: 2026-10-22
Previous Version: 42.1.0
New Version: 42.2.0
Patient data: not touched. No database change. No EMR screen changed.

--------------------------------------------------------------------------------
1. WHAT WAS WRONG
--------------------------------------------------------------------------------
Double-clicking Start-Borkeo-WiFi.bat closed the window at once.
The file started the EMR with "npm" without "call". npm is itself a batch
file, so Windows never came back to the "pause" line: when the server could
not start, the window closed before the error message could be read.
The usual reasons the server cannot start are:
  - the EMR is already running in another window (port 3001 is in use);
  - Node.js is not found;
  - the ZIP was opened but not extracted.

--------------------------------------------------------------------------------
2. WHAT CHANGED
--------------------------------------------------------------------------------
Start-Borkeo-WiFi.bat now:
  - starts the server with Node directly (no npm);
  - finds Node on the PATH, or in C:\Program Files\nodejs, or in the user's
    AppData\Local\Programs\nodejs;
  - checks first, with a clear message, that the EMR files are next to it,
    that Node.js is installed and that port 3001 is free;
  - keeps the window open on any error, so the message can be read.
The EMR itself starts exactly as before (same server, same data file).

Checked from Windows cmd in a test copy: normal start; port 3001 already in
use; Node.js not found; batch file without the EMR files. Each error stays on
screen with "Press any key to continue".
npm test: 903 of 903 pass. npm run check:khmer passes.

--------------------------------------------------------------------------------
3. FILES
--------------------------------------------------------------------------------
  Start-Borkeo-WiFi.bat      starts Node directly, checks, stays open on error
  package.json               version 42.2.0

--------------------------------------------------------------------------------
4. INSTALLATION (one step at a time)
--------------------------------------------------------------------------------
The files are already updated in this folder.

Step 1: Close any open EMR server window.
Step 2: Double-click "Start-Borkeo-WiFi.bat".
Step 3: If the window shows [ERROR], read the message and do what it says
        (for example close the other EMR window), then double-click again.

For Antigravity (only when applying to another copy of v42.1.0): apply the
code change in section 5 exactly (it keeps each file's line endings), then
run "npm test".
