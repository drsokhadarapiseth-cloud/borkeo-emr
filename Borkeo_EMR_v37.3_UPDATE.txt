BORKEO EMR v37.3 — FAST KH/EN LANGUAGE SWITCHING
One file supports v37.1 OR v37.2 as the starting version.
Contains actual tested code patches. Do not paste individual snippets over existing files.

CONFIRMED CAUSE
The language action was invoking clinical synchronization and full patient-context restoration in addition to translation. In the IPD module it re-filled registration/discharge/nursing forms, fetched payment data and reactivated the requested panel. Another record module re-ran treatment routing, which could dispatch specialty-form change events. The old language button also scheduled duplicate refreshes alongside the canonical language event. Bulk label replacements then generated more mutations for the translation observer to process.

v37.3 FIXES
- Language changes update displayed labels/header text without restoring saved patient data into unsaved forms or loading payment status.
- Do not reopen/reselect OPD/IPD/nursing panels merely because the language changed; preserve the active specialty/view.
- Run initialization synchronization once, rather than repeating department/field/nursing-order synchronization on every toggle. Real data-edit handlers remain intact.
- A repeated selection of the currently active language does nothing. Legacy button and canonical KH/EN events share one scheduled refresh per module.
- Only replace dictionary/static text and attributes if they changed. Pause the language observer during its own bulk translation, then resume observation even if translation fails. Permission observers and backend permissions remain intact.
- Preserve per-workspace language selection, Khmer/English labels, patient fields, prescriptions, medication times, Triage transfer/Edit behavior, and current ward/location.
- Includes all earlier v37.2 performance improvements if they are not installed, including smaller patient lists, unchanged-order redraw avoidance and non-empty demo-database protection.
