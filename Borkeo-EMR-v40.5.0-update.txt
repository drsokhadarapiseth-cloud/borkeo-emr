ERRORS FOUND AND FIXED IN v40.5.0
1. The nationality list file (nationalities.js / nationalities.css) was
   never sent by the server (error 404), so the nationality picker in the
   record did not work. Both files are now served.
2. Once loaded, the nationality picker crashed on every record. Fixed.
3. Saving a record failed with error 500 ("Gazetteer provinces.json not
   found") if the EMR was started from a folder other than the program
   folder. The address data is now always found from the program folder.
   (Start-Borkeo-WiFi.bat and npm start were not affected.)
After the fix: no errors on the doctor or nurse record pages.
