Borkeo EMR Update Note: Version 44.1.0
Update plan #1: online hosting (Docker / Railway) and production security
================================================================================

Date: 2026-10-24
Previous Version: 42.3.0 (restored baseline)
New Version: 44.1.0
Patient data: not touched. No database table change. .gitignore unchanged.

--------------------------------------------------------------------------------
1. WHAT CHANGED
--------------------------------------------------------------------------------
a) Online hosting files: Dockerfile, .dockerignore, .env.example (template,
   no real secrets), docs/DEPLOY.md (Railway step by step).
b) DATA_DIR: one permanent folder for the database (DATA_DIR/emr.sqlite),
   patient uploads (DATA_DIR/uploads) and backups (DATA_DIR/backups).
   Not set = today's locations on the hospital computer.
c) Online only (NODE_ENV=production or EMR_MODE=production):
   - Superuser password comes from SUPERUSER_PASSWORD (at least 12
     characters). It is never logged and changes only when the setting
     changes. If it is missing or too short, only the Superuser account is
     turned off; the server still starts and all other staff can sign in.
   - The shared 1234 ward accounts are not created. The log warns how many
     active accounts still use 1234.
   - The login page hides the account list and quick role picker.
d) TRUST_PROXY=true: behind Railway, login lockout and the audit log record
   the user's real address.
e) GET /api/health returns {"ok":true} (no login, no patient data).
f) Admin, Vice Director and Director can list and download database backups
   (GET /api/admin/backups and /api/admin/backups/latest). Every download is
   written to the audit log.
g) Version 44.1.0 in package.json, the login page and server.mjs.

--------------------------------------------------------------------------------
2. WHAT DID NOT CHANGE (HOSPITAL COMPUTER)
--------------------------------------------------------------------------------
A normal "npm start" or Start-Borkeo-WiFi.bat is not online mode:
- Superuser still signs in with 1234; all ward accounts keep working.
- The login page still shows the account list.
- Database, uploads and backups stay in the same folders.
- All roles, screens, clinical, pharmacy, laboratory and finance logic are
  unchanged.

Step 4. Start again as usual:  npm start   (or Start-Borkeo-WiFi.bat)
Step 5. Sign in and check the login page shows v44.1.

confirm the files in section 3 match; no code needs to be pasted.

database online without approval.
