BORKEO EMR v37.9 - BOTTOM FORM CONTROLS
BASE: package 37.8.0 in the current user project, Borkeo_EMR_v37.1.
TARGET: package 37.9.0 and visible v37.9.

APPROVED CHANGE
Move the shared Edit/Save, Cancel and status toolbar below the form on Registration, Triage and every other encounter form using this toolbar (OPD, IPD, Nursing Care, daily follow-up and discharge). Remove the toolbar Print button on Registration only. Retain printing on the other forms. Preserve the existing Khmer labels, required-field checks, role permissions, approval workflows and clinical/financial behavior. No patient data or photos are part of this patch.

IMPLEMENTATION
The encounter editor inserts its toolbar immediately after the page containing the active form, rather than before that page. Registration removes the toolbar Print element when creating the toolbar; other views retain the existing print handler. The toolbar remains outside the form's read-only controls and required-field validation scope. The existing Edit/Save and Cancel handlers are unchanged. Package, visible version and affected asset cache queries advance to 37.9.

VALIDATION
35 focused automated checks passed in a disposable copy with synthetic facility defaults and in-memory databases. Coverage includes version consistency, required fields, absence of EN controls, clinical scope and receipt/discharge permissions, completed-Triage edits, approved corrections/deletion, invoice permissions, read-only management history and printing.
13 existing browser scenarios passed in a fresh temporary Edge profile. The actual Registration layout was also measured to confirm its toolbar is below the form. Existing View/Edit/Save and required-field checks still passed. Tests used synthetic records only.
