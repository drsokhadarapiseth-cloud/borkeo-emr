1. SUMMARY OF CHANGES
--------------------------------------------------------------------------------
1. Patient List Deduplication by Health ID (`public/patient-list.js`):
   - When multiple patient records or visits share the same Health ID (`healthId`),
     the patient list displays only 1 entry representing the newest record.
   - Preserves triage today queue items and handles records without healthId cleanly.

2. Edit Choice Action Dialog (`public/patient-list.js`):
   - Clicking the pencil edit icon (`[data-request-edit]`) on any patient row
     pops up an action choice window:
     - «កែប្រែព័ត៌មាន» (Edit Information): Opens the patient consultation/registration edit mode.
     - «បន្ថែមកំណត់ត្រាថ្មី» (Add New Record): Directly starts a new intake/visit for the patient (`newVisitFrom`).
     - «បោះបង់» (Cancel): Closes the dialog.

3. Minor Navigation / Return to Patient List (`public/app-shell.js`, `public/patient-list.js`):
   - Clicking view or edit in patient list appends `from=patient-list` to navigation URLs.
   - The breadcrumb bar on `/emr` and `/record-viewer` includes a direct link back to `បញ្ជីអ្នកជំងឺ` (`/patient-list`).
   - Registration views opened from patient list display a top return bar (`‹ បញ្ជីអ្នកជំងឺ`).

4. Testing & Verification:
   - Added automated unit test `tests/v438-patient-list-dedup-and-actions.test.mjs`.
   - Updated version checks across package.json, server.mjs, login.html, and smoke tests.
   - Passed 100% of tests and strict Khmer copy checks.
