5. HOW TO RUN THE SYSTEM NOW
================================================================================
Normal mode (real patient database, password required):
1. Start the server:
    npm start
2. Open in your browser:
    http://localhost:3001
3. Sign in with your own username and password.

Demo mode (username-only demo accounts, separate demo database, this computer only):
Demo accounts (admin, registration, triage, doctor_medicine, etc.) only exist
when EMR_MODE=demo is set. A plain "npm start" does NOT enable them.
In PowerShell:
    $env:EMR_MODE = "demo"; npm start

================================================================================
6. HOW TO INSTALL AN UPDATE (ANTIGRAVITY), ONE STEP AT A TIME
================================================================================
Step 1. Close the running EMR server (Ctrl+C in its window).
Step 2. Back up the data folder (data/ or Borkeo_EMR_Data in your user folder).
Step 3. Place the update text file (Borkeo-EMR-v44.x.0-update.txt) in the
        project folder.
Step 4. In Antigravity, ask it to read that file and apply it to the project.
Step 5. Run: npm test
Step 6. Run: npm run check:khmer
Step 7. Start the server (section 5) and sign in with each role to check the
        banner, Switch Role, Change Password, Log Out and navigation.
