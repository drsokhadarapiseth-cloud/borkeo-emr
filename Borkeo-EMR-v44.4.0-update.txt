--------------------------------------------------------------------------------
1. WHAT WAS WRONG
--------------------------------------------------------------------------------
The EMR had no NPCA beneficiary identity link, no clinical visit export, no
certification submission queue and no processing status. Registration cards
and sticker sheets had to be made by hand.

--------------------------------------------------------------------------------
2. WHAT CHANGED
--------------------------------------------------------------------------------
a) Registration cards: an automatic card with barcode / QR for each registered
   patient, and printable sticker sheets.
b) NPCA (v1.4) integration, OFF by default (NPCA_ENABLED=false):
   - configurable settings and OAuth token handling;
   - verified beneficiary selection at Registration;
   - official Excel code mappings; visit builder with local validation;
   - a durable submission queue with retries and reconciliation;
   - status polling and review pages; record and Billing status badges;
   - optional clinical assessment / referral fields.
   Unknown mappings or missing clinical data block a claim; nothing is sent.
c) Stock and financial calculations are unchanged.
d) Details: docs/npca/INTEGRATION.md, OPEN-QUESTIONS.md, VERIFICATION.md.

--------------------------------------------------------------------------------
3. INSTALLATION (one step at a time)
--------------------------------------------------------------------------------
Step 1: Close the EMR server window (or press Ctrl + C in it), and make a
        database backup with the usual backup button or script.
Step 2: In the project folder run: git pull
Step 3: Double-click "Start-Borkeo-WiFi.bat", then press Ctrl + F5 once in
        the browser.
Step 4: Leave NPCA_ENABLED=false. Turn it on only after NPCA answers
        docs/npca/OPEN-QUESTIONS.md and supplies test credentials; test with
        synthetic patients and the local mock first.

For Antigravity: this folder already contains the update. On another computer
run "git pull", then the steps above, then "npm test" and
"npm run check:khmer". The full code change is the Git commit "v44.4.0" on
master (see git log).
