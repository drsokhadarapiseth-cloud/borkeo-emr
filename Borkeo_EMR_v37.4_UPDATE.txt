BASE: the supplied Borkeo_EMR_v37.3.zip, package version 37.3.0.
The ZIP's enclosing directory is named Borkeo_EMR_v37.1; use package.json to identify the installed version.
TARGET: package 37.4.0 and visible v37.4. One targeted patch; preserve other changes.

WHAT WAS REPRODUCED
The translation observer processes newly inserted text inside Paraclinic by traversing its ENTIRE containing panel for EACH text node. A dynamic update can therefore repeatedly translate the same large subtree. The specialty iframe observer likewise rescans all controls after any text/child mutation. Translation-generated mutations are observed again. This work runs in MutationObserver microtasks and can block browser input/painting.
The nationality language handler also rebuilds all select options, and is invoked through both the main language function and the language event.

FIX
- Keep the KH and EN buttons, existing translation dictionaries and per-workspace preference.
- Translate an added text node directly instead of rescanning its entire panel.
- Coalesce repeated changed nodes and nested subtrees into a queue. Process small batches in scheduled tasks with an 8ms time budget between nodes, allowing the browser to handle input/paint. A single subtree can still take longer than 8ms.
- Pause only the translator's own observer while it writes labels, then resume it in finally. Process queued external changes; skip removed nodes. Permission and clinical observers remain enabled.
- Specialty iframes use incremental translation instead of full-document rescanning on each mutation.
- Change ethnicity option labels in place once per language. Preserve option objects, selected values, search text and listeners; avoid repopulating the dropdown twice.
- Update script cache versions and release metadata. No runtime dependency, API, database schema, patient-record or workflow changes.
