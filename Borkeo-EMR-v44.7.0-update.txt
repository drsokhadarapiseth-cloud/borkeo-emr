--------------------------------------------------------------------------------
1. WHAT CHANGED
--------------------------------------------------------------------------------
a) Compact workspace (v43.1): tighter spacing on desktop; the ANC record and
   patient details fit phone and tablet widths without sideways scrolling.
b) Consultation cards (v43.2): on the patient record, vitals cards (BP, pulse,
   temperature, SpO2, respiratory rate, BMI), structured HPI and physical
   examination cards, quick diagnosis search and a treatment plan with a task
   checklist (public/emr-consultation-workspace.js and .css).
c) View switcher (v43.3): clinicians choose one of three views:
     1. Integrated view: the cards on top, the full classic hospital forms below
     2. Compact view: the cards only
     3. Classic view: the full classic forms only, as in v42.3
   The classic forms, their fields and how they save are unchanged.
d) The navigation buttons, hospital banner, Switch role, Change password and
   Log out stay visible for every role (the v43.4 hiding is NOT included).
e) Version 44.7.0 in package.json, the login page and the server.

--------------------------------------------------------------------------------
2. INSTALLATION (one step at a time)
--------------------------------------------------------------------------------
Step 1: Close the EMR server window (or press Ctrl + C in it).
Step 2: In the project folder run: git pull
Step 3: Double-click "Start-Borkeo-WiFi.bat" (or run npm start).
Step 4: In the browser press Ctrl + F5 once, open a patient record and try the
        three views.

For Antigravity: this folder already contains the update. The full code change
is the Git commit "v44.7.0" on master (git log). After pulling, run
"npm test" and "npm run check:khmer".
