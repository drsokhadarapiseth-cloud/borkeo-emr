1. SUMMARY OF CHANGES
--------------------------------------------------------------------------------
1. Patient List Age Column (`public/patient-list.js`):
   - Refined the table row renderer (`<td data-column="age" class="patient-age">`)
     so that only the age badge (e.g. "7 ឆ្នាំ", "71 ឆ្នាំ") is displayed.
   - Removed the preceding date of birth string (`patient.dateOfBirth`) from the
     rendered cell, ensuring a clean and focused age presentation matching user
     requirements.

2. Resilient Age Calculation Fallback:
   - Updated `ageLabel(patient)` in `public/patient-list.js` to automatically
     calculate completed age in years from `patient.dateOfBirth` as of their entry
     date (or current date) if `patient.age` is blank.

3. Testing & Verification:
   - Added unit test `tests/v436-patient-list-age-only.test.mjs` validating the
     omission of DOB in the table row markup and age calculation fallback.
   - Verified 100% pass across all 992 automated test suites.
   - Verified Khmer language consistency with `npm run check:khmer`.
